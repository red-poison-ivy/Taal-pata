# Taal Pata (তাল পাতা) — Android APK & Tablet Studio

Welcome to **Taal Pata (তাল পাতা)**, your full-featured stylus note-taking, subject folder organizer, and HD PDF annotation studio.

## Two Ways to Install on Your Android Tablet / Phone

### Option 1: Instant Zero-Build Install (Direct on Tablet)
1. Copy `app/src/main/assets/index.html` (or open the live app) in **Chrome** or **Brave** on your Android tablet.
2. Tap the browser menu (`⋮`) -> **Add to Home screen / Install app**.
3. It launches full-screen like a native app with full stylus (`pen`) vs. finger (`touch`) separation.

### Option 2: Compile Native `.apk` (`Taal-Pata.apk`)
Because this folder is a complete native Android Studio project (`com.taalpata.notes`):
- **Via GitHub Actions (No PC setup required)**: Upload this project folder to a free GitHub repository, click the **Actions** tab -> **Build Taal Pata APK**, and download `app-debug.apk` directly to your tablet.
- **Via Android Studio**: Open this folder in Android Studio and click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
